# 初一食午薪資管理 APP

這是一套可部署到 Netlify 的早餐店薪資、出勤與員工核對系統。資料可先存在瀏覽器，管理者登入後會同步至 Netlify Blobs；原始打卡照片只用於辨識，不會永久存入雲端。

## 主要功能

- 時薪依分鐘計算，可設定平日、週末、國定假日及尖峰時段費率。
- 月薪依每日排班計算提早與延後加班，支援跨日班別。
- 每位員工都有費率生效歷史；已核准月份會保存不可變更的薪資快照。
- 已內建匯入 `初一食午工資新版(2026年).xlsx` 的 1～6 月資料，共 515 筆每日出勤；舊月份依原工資簿實領金額保存為鎖定快照。
- 每週可設定不同上、下班時間，也可針對單日覆寫班別。
- 年假依到職日估算，支援年假取得／扣回帳本、部分日請假、病假與事假扣款。
- 獎金、禮金、加給與扣款可設定數量、單價及生效期間。
- 國定假日、颱風日、平日與週末以不同顏色顯示。
- 打卡照片可用 Gemini 協助辨識，無法確定的結果會保留給人工核對。
- 可匯入 CSV 出勤資料，也可使用員工 PIN 在店內快速上下班打卡。
- 月結流程包含草稿、提交覆核、核准鎖定及已發薪。
- 結算前會檢查漏打卡、重疊時段、超長工時、排班缺勤、負數年假與最低工資警示。
- 可匯出 CSV、Excel、JSON 備份及 9:16 員工薪資出席 JPG。
- 可建立有期限的員工核對連結，員工可回覆「確認無誤」或提出問題。
- 提供月薪資變化、人事成本與人事成本占營業額比例。
- 手機版具固定底部導覽，出勤文字與操作按鈕已放大。

## 專案結構

- `salary_app/`：主要薪資管理 APP
- `employee_portal/`：員工私人核對頁
- `netlify/functions/`：雲端資料、AI 辨識與員工核對 API
- `dashboard_cost/`：原有成本分析頁
- `netlify.toml`：Netlify 建置、函式與安全標頭設定

## Netlify 初次設定

1. 將整個 `Breakfast` 資料夾上傳到 GitHub。
2. 在 Netlify 連接該 GitHub 專案並重新部署。
3. 到 `Project configuration` → `Identity` 啟用 Netlify Identity。
4. 將註冊方式設為 `Invite only`，只邀請需要使用後台的人員。
5. 由第一位登入的管理者進入「規則與備份」→「管理者角色與權限」，依受邀 Email 指派角色。
6. 在 Netlify 的 `Environment variables` 設定 `GEMINI_API_KEY`。

登入 Netlify Identity 的管理者可直接使用 AI 辨識，不必再輸入共用辨識密碼。若仍需讓未登入者使用 AI，才另外設定 `TIME_CARD_API_TOKEN`。

## 角色權限

- 店主：完整權限、角色設定、強制覆蓋與月結核准。
- 薪資管理者：出勤、薪資與月結操作，可建立員工核對連結。
- 現場主管：只可處理出勤相關資料。
- 唯讀會計：可查看與匯出，但不能修改。

角色不會自動建立 Netlify 帳號。請先在 Netlify Identity 邀請使用者，再於 APP 內用相同 Email 指派角色。

## 建議使用流程

1. 在「員工設定」建立員工、費率生效日、排班、到職日與選用的打卡 PIN。
2. 在「規則與備份」確認倍率、排休基準、病假比例與最低工資警示基準。
3. 每日人工新增、CSV 匯入、PIN 打卡或上傳照片辨識出勤。
4. 月底先處理儀表板的例外項目，再提交覆核。
5. 核准薪資後系統鎖定月份並保存快照；發薪後標記為已發薪。
6. 開啟員工明細，可下載 JPG 或建立限時核對連結。

首次開啟新版時，系統會自動把 2026 年 1～6 月工資簿資料合併到本機資料；既有的同日出勤與既有月結快照不會被覆蓋。管理者登入後，店主或薪資管理者會將這次資料移轉同步至 Netlify。

## 資料與安全

- 未登入時資料保存在瀏覽器 `localStorage`。
- 登入後資料會同步至 Netlify Blobs，並保留前一版、每日備份、月結快照及伺服器端操作紀錄。
- 員工 PIN 只儲存加鹽後的 SHA-256 雜湊，不保存明碼。
- 員工核對連結使用不可猜測的權杖，預設 7 天到期，可在薪資頁查看員工回覆。
- 原始打卡照片不會寫入備份或 Netlify Blobs。
- 重大薪資政策或勞動法規仍應由店主或專業人員確認；APP 的法規基準欄位與警示不等同法律意見。

## 本機檢查

安裝套件後可執行：

```powershell
pnpm run build
pnpm run check
```

`build` 會重新產生 Identity 瀏覽器套件；`check` 會檢查主要 JavaScript 與三支 Netlify Functions 的型別。
